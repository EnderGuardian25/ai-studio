## Contract (design §5)

`scripts/lib/uiInvariants.mjs` (pure, no fs, no git) exports:

- `AUDIT_SET`: the 47 paths.
- `collectAttrs(source, file)`: parse with `ts.createSourceFile(file, text, ts.ScriptTarget.Latest, true, ts.ScriptKind.TSX)`. Walk `JsxAttribute` nodes; keep names matching `aria-*`, `data-testid`, `role`, `id`, `htmlFor`, `type`, `name`, `href`, `/^on[A-Z]/`. Value = string literal text, or the initializer expression's `getText()` with whitespace collapsed; a valueless attribute gets a stable marker (e.g. `true`). A `JsxSpreadAttribute` is recorded as `...<expr>`. Returns entries `{ key: 'attr=value', file }`.
- `diffAttrs(base, head)`: multiset over the whole scope, keyed by `attr=value` only (the file is not part of the key, so moves pass). Returns added and removed items with counts and the files they came from.
- `parsePermits(auditMd)`: parse the family tables (columns ID, File, Element, Class, Reference, Fix, Permits, Status). Return permits with their row ID and status, plus the set of row IDs and the files that have rows (for `--coverage`).
- `judge(diff, permits)`: a permit `-<file>:<attr>=<value>` / `+<file>:<attr>=<value>` consumes one count of its key's removal / addition. Permits on rows whose Status is not `approved` or `closed …` fail. A permit citing an unknown row fails. **Citation rule (decided by the orchestrator):** each permit carries the `rowId` of the row whose Permits cell holds it; `parsePermits` also returns `rows: Map<id, status>`. `judge(diff, permits, rows)` fails a permit whose `rowId` is absent from `rows` or is not a valid `A-NNN` ID, and fails on a duplicated row ID. Document this in the module header. Unused permits are warnings. Returns `{ ok, failures, warnings }`.

`scripts/check-ui-invariants.mjs` (CLI): `BASE = 'c45ed3dc'`; file lists via `git ls-tree -r --name-only <ref> src/app src/components` (filter `.tsx`); sources via `git show <ref>:<path>` for BASE and the working tree (or `HEAD`; prefer the working tree so uncommitted edits are checked, and say which in the header); audit via `fs`. Prints each unpermitted added/removed key with its file(s). Exit 1 on any failure. `--coverage`: exit 1 when an `AUDIT_SET` path has no row. Output: keys and paths only.

`audit.md`: header (baselines `9f829456`, `c45ed3dc`; counts placeholder; the column legend) and four empty family tables G1–G4 with the design §3 columns. T4 fills the rows.
