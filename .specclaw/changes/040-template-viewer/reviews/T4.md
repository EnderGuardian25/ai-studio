## Findings

### [NOTE] tests/e2e/template-viewer.test.ts:93 and :112 - selector breadth

`page.getByRole('button', { name: /^Template/ }).first()` relies on `.first()`. The button-name regexes at :98 and :103 (`new RegExp(a.name)`) are not escaped. The stamp makes them unique and digits and spaces are safe, so this is not a bug today. Prefer a scoped locator if the wizard gains another "Template..." button.

### [NOTE] tests/e2e/template-viewer.test.ts:38-44 - afterEach if beforeEach fails early

If `loginAs` throws in beforeEach, afterEach runs with `api` undefined and `briefDraftIds(api)` throws, which hides the original error. If the kit POST returns a non-kit body, the DELETE hits `/undefined`. Both are cosmetic. A kit that was minted before a later template POST failure is still deleted, because `kit.id` is set.

### [NOTE] tests/e2e/template-viewer.test.ts:39-41 - draft sweep

The sweep deletes every brief-draft that is new since `before`. That is safe only because playwright.config has `workers: 1` and `fullyParallel: false`. It is the same pattern as the other suites. If parallelism is ever turned on, it would delete other tests' drafts.

### [NOTE] tests/e2e/a11y.test.ts:1213-1216 - AC-06 scope

The axe scan covers the page with the dialog open. The iframe is sandboxed and its content is not scanned, which is acceptable. `expect(page.locator('iframe[title^="Preview of"]')).toBeVisible()` proves the viewer is mounted before the scan, so the test is not vacuous. The kit is pushed to `mintedKits` and cleaned in the existing afterEach.
